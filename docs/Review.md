## Toy16 on word-level RTL: retirement refines the ISA

The word-level core retires like the ISA after one reset cycle, from any
power-up store (registers, register file, data memory, instance state), with the
instruction bus answered by `imem`, and reports a retirement (or has reported
the final halt) at least every two cycles. Implementation hole:
`Toy16.Word.design`.

```lean
HDLean.Toy16Rtl.Challenge.correctness (imem : Addr → Word) (s₀ : Store) (rst : Nat → Bool) (hr : rst 0 = true)
  (hd : ∀ (t : Nat), 0 < t → rst t = false) :
  ∃ regs mem,
    have retire := fun t => retireAt Word.design imem s₀ rst (t + 1);
    RetiresLike retire (isaRetire imem (ArchState.atReset regs mem)) ∧ Progress 2 retire Retire.halt
```

Axioms: propext, Classical.choice, Quot.sound.

## Single-port RAM on the memory primitive

For every power-up store (memory contents and read register) there is an
initial reference RAM state such that, under any inputs and reset sequence, the
read port shows the read-before-write reference RAM's read word on every cycle.
The memory is an RTL memory, not flip-flops. Implementation hole:
`RAM.Word.design`.

```lean
HDLean.RAMRtl.Challenge.correctness (a w : Nat) (ha : 0 < a) (hw : 0 < w) (s₀ : Store) (xs : Nat → Array Nat × Bool) :
  ∃ m₀,
    ∀ (t : Nat),
      readWord w (RAM.Word.design a w) ((machine (RAM.Word.design a w)).stateFrom s₀ xs t) =
        (ram (2 ^ a) w).runFrom m₀ (fun n => request a w (xs n).fst) t
```

Axioms: propext, Classical.choice, Quot.sound.

## Toy16, bit-level node graph (legacy)

The emitted CPU's retirement bus refines the ISA after one reset cycle, for
arbitrary power-up register and data-memory contents. The two-cycle progress bound
rejects a core that stalls. Implementation hole: `DagPhysical.hardware`.

```lean
HDLean.Toy16.Challenge.correctness (imem : Addr → Word) (s₀ : Fin (268 * 16) → Bool) (rst : Nat → Bool)
  (hr : rst 0 = true) (hd : ∀ (t : Nat), 0 < t → rst t = false) :
  ∃ regs mem,
    have retire := fun t =>
      Physical.observe (((DagPhysical.hardware imem).denote ⋯).runFrom s₀ (fun n => (Fin.elim0, rst n)) (t + 1));
    RetiresLike retire (isaRetire imem (ArchState.atReset regs mem)) ∧ Progress 2 retire Retire.halt
```

Axioms: propext, Classical.choice, Quot.sound.

## Asynchronous FIFO (two clock domains)

After a reset startup in both domains, the observed ports follow the queue
reference for every power-up state, clock interleaving and sampling oracle.

